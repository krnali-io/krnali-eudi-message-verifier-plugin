EUDI TEST WALLET

From your phone.
With a signed credential.

Use fictional identity details for this sandbox test. You will approve a real wallet presentation of an issuer-signed test PID.

1. Install the wallet

iPhone: EUDI Reference Wallet Trinsic ↗
Open this invitation on your iPhone. Install Apple's TestFlight if prompted, then accept and install the wallet if a compatible beta build is available.

iPhone compatibility check pendingThis is Trinsic's distribution of the EUDI reference wallet, configured to trust Trinsic's certificates. Its documented setup uses FormEU test credentials. A successful presentation to this verifier has not yet been confirmed.

Android: official EUDI wallet APK ↗
Requires Android 10 or later. The release is labelled Demo because it uses test services.

iPhone alternative: build the official app ↗
Requires iOS 17 or later, Xcode on a Mac and app signing, or an approved distributed build.

2. Add a test identity

Trinsic iPhone build: create your wallet PIN. Choose Add my Digital ID → issuer.eudiw.dev → PID Combined. Continue to the issuer, select FormEU → Submit, and enter fictional details. Birth date, family name, given name and nationality are required. Select Authorize, wait for issuance, then tap Done. Trinsic's setup instructions ↗

Official reference app: create your wallet PIN. Choose Documents → + → From list → PID. At the issuer choose Country Selection → FormEU, enter fictional details, then finish issuance.

Keep the given name and family name for the expected-name field in the console.

3. Check the wallet

On your phone, open the official EUDI verifier ↗. Request the PID given name and family name, open the wallet, and approve sharing. Issuing a credential alone does not confirm presentation compatibility. If the wallet rejects this request, note the error before trying this verifier.

4. Test a request

Same iPhone: open a fresh verification link in Safari. Tap Verify with your EU wallet, then Open wallet. Unlock the wallet, review the requester and two requested name attributes, and approve sharing. Return to the verification page and check the console result.

Computer and phone: open a fresh verification link on your computer and tap Verify with your EU wallet. Open the wallet on your phone and use its QR scanner to scan the displayed code. Review and approve the request in the wallet. Keep the computer page open for the result.

If Open wallet does nothing

The browser-to-app handoff has not completed. Make sure the wallet is installed and already contains your test PID. If you opened the link inside a messaging app, use a fresh link in Safari. Try the computer-and-phone QR route to check whether the wallet can read the request directly.

If the wallet only shows its home screen, or reports an unsupported request, unknown requester or missing credential, the check has not succeeded. Note the exact error and wallet version. Trinsic compatibility with this verifier is still unconfirmed; scanning a QR does not change certificate trust or protocol support.

Each link starts once. When switching devices after starting, create a fresh request rather than reloading the used link.
